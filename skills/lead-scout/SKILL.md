# Lead Scout

目标：**已核实的线索 = 没有自己网站的企业**，且通过*搜索该企业*确认——用途是向没有网站的企业推销网站。无需密钥：`web_search` 加浏览器即可完成全部工作，无需 API key。

## 规则——什么算“有网站”
只有拥有**自己的站点**（官方域名，如 `cafeborkar.com`、`artjuna.in`）的企业才算有网站。以下**不**算网站：
- **社交页面**——instagram.com、facebook.com
- **聚合平台 / 目录站**——zomato、swiggy、justdial、tripadvisor、magicpin、dineout
- 其 **Google Maps / Google Business** 商家信息

因此，如果搜索该企业后**只**出现上述内容，它就**没有网站 → 是一条线索**。

## 方法——靠搜索判断，绝不靠地图按钮
1. **获取候选名称——先 `web_search`**（除非搜索不可用，否则不要开 Maps）：
   - `web_search "<细分领域> in <城市>"` 返回企业及其域名。通常这一次搜索就能得出结论——只出现在聚合平台/社交平台、没有自己域名的企业就是你的线索。
   - 仅当 `web_search` 不可用/被限流时：用浏览器 `navigate` 到 `https://www.google.com/maps/search/<细分领域>+in+<城市>`，然后**一次** `snapshot`（snapshotFormat:`"text"`）/`evaluate` 一次性读取整个列表（绝不要截图或逐个点击每条商家）。`scroll`（to:`"bottom"`）后再 snapshot 获取更多。
2. **逐家企业用搜索判断**——这一步才决定“没有网站”：
   - `web_search "<企业名称> <城市>"`。（如果 `web_search` 被限流，就在浏览器里执行同样的查询：导航到 Bing / DuckDuckGo-html / Google 的结果 URL，然后 `snapshot`。）
   - 扫描结果：是否有结果是该企业的**自有域名**（按上述规则判断）？
     - **有** → 它有网站——跳过，不是线索。
     - **只有**社交 / 聚合平台 / Maps 结果 → **没有网站 → 是一条线索。**
   - 不确定哪个结果是它的？打开最靠前的非社交结果，`snapshot` 确认是谁的站点。
3. **报告**每条线索时附上**证据**：名称、区域/地址（如找到则附电话），以及*为什么*它是线索——例如*“搜索了‘Cafe Borkar Panaji’——只出现一个 Instagram 页面和一条 Zomato 商家信息，没有自己的网站。”*

## 电话 / 地址
从搜索结果或企业自己的社交页面读取。Google Maps 在界面里把电话藏在登录之后——不要跟那个面板较劲；号码通常就在搜索结果里或他们的 Instagram/Facebook 上。

## 反模式
- **绝不要因为 Google Maps 缺少“Website”按钮就判定“没有网站”。** 那只说明没人把站点关联到 Google——企业很可能有网站。唯一有效的判断方式是**搜索企业名称**，看它自己的站点是否出现。
- 不要截图商家信息再靠肉眼读，也不要逐个点进每条商家——用**一次** `snapshot`/`evaluate` 读取列表，再靠搜索判断。
- 不要为了查询或核实列表就派生一个子代理——就地完成；一次查询不需要一个团队。
- 不要报告你并未真正搜索过的线索；绝不要凭记忆编造电话号码。
- 如果发现自己重复同一操作却没有新结果，停下来，报告目前已有的内容。
- 不要把聚合平台/目录页面当作企业的网站或事实来源。
